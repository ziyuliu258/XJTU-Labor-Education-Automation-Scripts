# 西交在线学习 · AI 答题小助手

面向 `https://vpahw.xjtu.edu.cn/exam/…` 答题界面的油猴脚本。安装后，页面右下角显示助手面板，支持自定义 Chat Completions API、API Key 和模型 ID。

## 安装

1. 在使用答题网站的浏览器中安装 [Tampermonkey（油猴）](https://www.tampermonkey.net/)。
2. 点击油猴图标 → **添加新脚本**，删除默认内容。
3. 用文本编辑器打开 [`scripts/xjtu-ai-helper.user.js`](../scripts/xjtu-ai-helper.user.js)，把**全部内容**复制到油猴编辑器，按 `Ctrl+S` 保存。此安装方式见[油猴官方说明](https://www.tampermonkey.net/faq.php?q=Q102)。
4. 在原网站登录，**从课程页面进入考试**，刷新页面，查看右下角助手。该站点依赖课程页传来的状态，直接打开考试链接有时无法加载试卷。

Chrome 系浏览器如果没有运行脚本，请在油猴扩展的管理页面开启“允许用户脚本”；其他版本可按[油猴官方权限说明](https://www.tampermonkey.net/faq.php?q=Q209)开启开发者模式。还需允许油猴访问该学习网站。

## 配置接口和模型

展开 **API 与模型设置**，填写：

| 字段 | 填写方式 |
| --- | --- |
| API 地址 | 服务商给出的兼容接口根路径，例如 `https://你的接口域名/v1`；也接受完整的 `/chat/completions` 地址 |
| API Key | 该服务的密钥；无鉴权的本地服务可以留空 |
| 模型 ID | 服务商提供的准确名称，可手动输入或点击“获取模型”后选择候选 |
| 请求超时 | 默认 180 秒；推理模型较慢时可调大 |
| 批量间隔 | 默认 800 毫秒；服务限流时可增加 |
| 补充要求 | 可填写教材背景、课程术语或解释要求 |

点击 **保存设置 → 测试连接**。测试连接会发送一条简短模型请求，服务商可能计费；获取模型只请求模型列表，部分中转服务不支持模型列表，但仍可手动填写模型 ID。

脚本不会自动补 `/v1`，只在根路径后补 `/chat/completions`。例如 `https://host/compatible-mode/v1` 会变成 `https://host/compatible-mode/v1/chat/completions`。如果接口根路径本身不带 `/v1`，按服务商说明填写即可。

自定义服务首次连接时，油猴可能提示允许访问对应域名。跨域请求使用油猴的 [GM_xmlhttpRequest](https://www.tampermonkey.net/documentation.php?q=GM_xmlhttpRequest)，允许域名的规则见 [@connect 文档](https://www.tampermonkey.net/documentation.php?q=connect)。

### 导入配置

复制 [`examples/ai-config.example.json`](../examples/ai-config.example.json)，修改其中的 `baseUrl`、`model` 等字段，再点击面板里的 **导入 JSON 配置**。导入后核对地址，再测试连接。导入文件不会自动开启“记住密钥与请求头”。

**高级设置**提供两个 JSON 对象：

```json
{
  "X-Custom-Header": "你的服务要求的值"
}
```

```json
{
  "temperature": 0.2,
  "max_tokens": 4096
}
```

以上分别填入“自定义请求头”和“额外请求参数”。只添加模型实际支持的字段。不同推理模型可能使用 `max_completion_tokens` 或 `reasoning_effort`；不支持 `temperature` 的模型不要添加它。默认不设置这些参数，以减少兼容问题。

脚本使用 `POST …/chat/completions` 和 `GET …/models`，解析 `choices[0].message.content`。兼容接口协议示例可参考 [DeepSeek 的 Chat Completions 文档](https://api-docs.deepseek.com/api/create-chat-completion/)与[模型列表文档](https://api-docs.deepseek.com/api/list-models/)。本版本不直接支持原生 Anthropic Messages、Gemini generateContent 或 Responses 协议；这些服务需要提供 Chat Completions 兼容入口。

## 使用

1. 面板会自动识别试卷中的单选题和多选题。用下拉框、左右箭头切换题目，“定位”会滚动到原页面对应题目。
2. 点击 **分析这题**，查看建议选项、简短解析和不确定之处。展开“查看模型原始输出”可检查输出。
3. 核对后点击 **填入本题建议**，通过页面原有控件勾选，触发 React 的正常更新。
4. **批量分析**逐题请求，默认跳过页面已经作答的题目和已有分析结果。取消“批量仅分析页面上尚未作答的题目”，可分析未生成建议的已作答题。重做某道已有分析的题，请用“分析这题”。
5. **填入已分析建议**会填入当前试卷中有有效建议的文字题，包括覆盖这些题的现有勾选。图片题和空答案会跳过。
6. **停止**会中止当前任务。已生成的建议仍保留在当前页面会话中。交卷使用原页面的按钮。

模型输出格式不正确、返回不存在的选项或为单选题返回多个选项时，会阻止填入。单选和多选回填前均核对题干及选项；页面切换后旧结果会清除。

## 数据与保存

- 请求内容是所选题目的题干、选项和你填写的补充要求。脚本不主动读取登录凭据、学生资料或其他后台接口，也不向 API 携带学习网站的 Cookie。
- API Key 和自定义请求头默认仅在当前页面会话使用；勾选“记住密钥与请求头”后保存在油猴脚本存储中。该存储不是加密密码库。可用“清除密钥与请求头”删除。
- API 地址、模型和其他普通设置会保存。若你把凭据放在 API 地址的查询参数中，地址也会一起保存；尽量使用独立的 Key 输入框或请求头。
- 导出配置会移除 API Key、全部请求头和 URL 查询参数。若补充要求或额外参数中包含自行填入的敏感内容，请在分享配置前检查。
- 生成的答案、题目和原始模型输出只在内存中保留，刷新后清除。模型返回的文本以纯文本显示。

## 适配范围与验证

适配依据为 **2026-11-11** 该网站公开前端代码中的 `div[id^="jump"]`、选项段落和 Ant Design 单选/多选控件。此次没有使用你的登录会话，也没有使用真实 API Key 发起付费调用；验证使用与该站点同版 React 的本地模拟答题页面和模拟 API。

已通过 **35 项本地 Chromium 浏览器检查**，覆盖题目识别、单选/多选 React 状态更新、配置导入导出、凭据保存与清除、异常模型输出、限流、停止、超时、题目与路由变化、窄屏布局及面板隔离。[界面预览](assets/ai-helper-preview.png) 展示的是本地模拟页面，不是真实账户试卷。

图片题当前只提取文字，不发送图片，且禁止自动填入。填空、简答题以及网站后续变更的页面结构不在当前适配范围内。如果“已识别 0 题”，先确认已经从课程页正常进入试卷，等待题目加载后点击“重新读取”。

常见问题：

| 现象 | 处理 |
| --- | --- |
| 面板不出现 | 检查脚本是否启用、网站访问权限和浏览器的用户脚本权限，随后刷新 |
| HTTP 401 / 403 | 检查密钥、账户状态及模型权限 |
| HTTP 404 | 检查兼容接口路径及模型 ID |
| HTTP 429 | 检查余额/限流，稍后重试或增大批量间隔；脚本不会自动重试扣费请求 |
| 返回 HTML 或不是 JSON | 通常是把网页地址填成 API 地址，或网关返回了错误页 |
| 推理模型无正文/被截断 | 按服务商说明提高输出 token 上限，或切换模型 |
| 题目已变化 | 重新读取、重新分析后再填入 |

文件无需启动本地服务器，无第三方运行时依赖。删除或禁用油猴中的本脚本即可停用。
